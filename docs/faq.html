Arrow keys (or Vim's hjkl) don't repeat when I hold them down

This is macOS's press-and-hold accent popup intercepting the keystroke instead of letting it repeat — the same behavior you'd see holding a letter key in TextEdit. It's a system-wide default that most apps opt out of, but it has to be disabled per app. Run this in Terminal, then relaunch Notesidian:

defaults write com.milkbar.Notesidian ApplePressAndHoldEnabled -bool false

To put the default back: defaults delete com.milkbar.Notesidian ApplePressAndHoldEnabled.

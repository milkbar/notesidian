What's new in Notesidian

Every notable change, version by version. Notesidian 1.1 is now available on the Mac App Store. The format follows Keep a Changelog.

1.2.0 In development

Rendered Markdown now gets out of your way as you edit, a single ⌘K popover creates and edits every inline element, and fenced code blocks read as real blocks.

Added
  • ⌘K element editor. ⌘K opens a popover to create or edit the element under the caret — a web link, wiki link, callout, or code block — and pressing ⌘K again cycles through those types (starting at web link). Remove strips any element's markup while keeping its visible text.
  • Code blocks render as a block. A fenced ``` block shows as a softly-boxed, monospace region with its language labeled, instead of the fences collapsing to blank lines.
  • Rename notes. A Rename… item in a tab's right-click menu renames the current note (and can move it between folders), keeping the tab pointed at it.
Changed
  • Rendered Markdown gets out of your way. In preview mode the hidden syntax now behaves as if it isn't there: the caret (arrows, Vim h/l, clicks) steps over it, and Backspace/Delete edit the visible text — emptying an element's text removes the whole thing, so you never leave a stray ** or ]]. This spans bold, italic, code, strikethrough, headings, quotes, links, wikilinks, callouts, and code blocks. Wikilinks and embeds no longer reveal their raw source; edit a wikilink's target with ⌘K.
  • Today's Note is a fixed tab. The sixth tab is permanently the Today's Note tab (so ⌘6 and ⌘T match) and can't be dragged out of place.
1.1.0 On the App Store Available now on the Mac App Store

This release brings the editor closer to Obsidian's own: wikilinks, inline images, tags, callouts, and Vim mode. It also makes edits much harder to lose.

Added
  • Wikilink navigation. [[Note]] and [[Note|alias]] render as clickable links in preview; clicking one opens the note in Obsidian, creating it first if it doesn't exist. Editing a link now reveals its raw source while your cursor is inside it, so backspacing edits the text you see instead of the hidden brackets.
  • Wikilink autocomplete. Typing [[ suggests notes from your vault (filter as you type, ↑/↓ then ↵ or Tab to choose); the link and closing ]] are inserted for you.
  • Inline images. Embedded images render right in the editor's preview: ![[image.png]] (with Obsidian's |width syntax), ![alt](path), and remote ![](https://…). Source mode still shows the raw embed.
  • Markdown links render, too. [text](url) shows as an underlined, clickable link with the destination tucked away, and reveals its source when you edit it.
  • Tags, callouts, and frontmatter render in preview. #tag shows as a subtle pill (click to open Obsidian's search); > [!note] … callouts render as a colored block with an icon and title; a leading --- … --- YAML block is dimmed into a compact properties strip.
  • Spell & grammar check in the editor: the usual macOS underlines and right-click suggestions, plus an Edit ▸ Spelling and Grammar menu to toggle checking.
  • Vim mode (opt-in): modal editing (normal / insert / visual, : commands, / search) via a toggle in Settings ▸ Editor. Off by default; the setting syncs like the others. Opening a line with o/O continues the list and indentation, just like Return.
  • Toggle rendered / source with ⌘E (in addition to the header's </> button).
  • Advanced-formatting menu. A ⋯ button in the header toolbar inserts a code block, quote, or callout (> [!note]).
  • Make a task from the keyboard. ⌘. turns the current line into a task if it isn't one, or checks / unchecks the task you're on (or every task line in the selection), stamping the ✅ done-date just like clicking the box.
  • Paste or drag in an image. Pasting or dropping an image saves it into your vault's attachment folder (honoring Obsidian's attachmentFolderPath) and embeds it as ![[image]].
  • Paste a link. Paste a URL over selected text and it becomes a [text](url) Markdown link (single-line selections; http(s)/scheme URLs and mailto:).
  • Auto-close [[. Typing the second [ inserts the closing ]] and parks the caret between them, ready to type or autocomplete a wikilink, scoped to [[ only.
  • Fuzzy note search. The ⌘O picker matches by subsequence (type “prjx” to find Projects/Project X), ranks the closest matches first, and bold-highlights the letters that matched.
  • Proximity-ordered note picker. ⌘O lists notes grouped by closeness to the current note: siblings first, then peer folders, then everything else, with paths shown relative to the shared parent for nearby notes.
  • Create notes from the picker. Typing a name that doesn't match shows a “Create note …” option that makes the note next to the current one and binds it to the tab.
  • Keyboard navigation (all on ⌘⌥, so the editor keeps its own ⌘-arrow shortcuts): ⌘⌥← / ⌘⌥→ previous / next tab; ⌘⌥↑ / ⌘⌥↓ previous / next note in the same folder; ⌘T jumps to the Today's Note tab.
  • Open in Obsidian. Jump from a note straight to the full Obsidian app, from the ⋯ menu, or by ⌘-clicking or double-clicking the note title in the header. Capture here, go deep there.
  • Insert date / time. ⌘; inserts today's date (in your vault's daily-note format) and ⇧⌘; inserts the current time, at the caret.
  • Daily-note template. When a Today tab first opens a day that doesn't exist yet, the note is created from the Daily Notes plugin's template (if configured), with the core {{title}} / {{date}} / {{time}} (and {{date:FORMAT}}) tokens filled in. Templater <% … %> syntax is left untouched.
  • Notes remember where you left off. Each note's caret and scroll position are restored when you reopen it, so the quick-open loop lands you exactly where you were. The first time you open a note, the caret starts at the end, ready to append.
  • Find in note (⌘F). A single case-insensitive search box (Obsidian-style) with a match count and next / previous, styled to match the rest of the UI. It also seeds from the current selection and jumps to the first match.
  • Keyboard-shortcut help (⌘/). A centered panel listing every in-panel shortcut.
  • Per-vault tab configuration. Each Obsidian vault keeps its own set of tab assignments, synced via iCloud, so the same vault matches across your Macs no matter where it lives on disk, and a different vault starts with its own layout.
  • Resizable width. The resize grip moved to the bottom-left and now adjusts both width and height, growing from the fixed top-right corner. Tabs and the header scale to stay readable; width persists and syncs like height.
  • Note-name cue. When the loaded note changes, the header briefly shows the note's full name (middle-truncated) for about a second, then fades back to the toolbar.
  • Tab-switch swipe. Switching tabs slides the content in from the direction of the move, for a bit more polish.
  • Just start typing. On a tab with no note assigned (or no vault yet), the prompt is keyboard-actionable: press Return or Space to choose a note / vault without reaching for the mouse.
  • Placeholder text. An empty note shows a dim “Start writing…” hint.
  • Reduce Motion. With Reduce motion on, the panel zoom, tab-switch slide, and settings grow fall back to a quick crossfade (or nothing).
  • Vault path in Settings. The current vault's path is shown under the Choose… button, with the home folder abbreviated to ~ and long paths middle-truncated.
  • VoiceOver labels on the note tabs, formatting toolbar, settings controls, resize grip, and menu-bar item. The note picker and shortcut help open as centered, arrow-less panels.
Changed
  • The selected tab is highlighted with an outline instead of a filled color, so every tab keeps its own tint and stays recognizable whether or not it's selected.
  • Increase Contrast support. With Increase contrast on, the header band, tab pills, and settings recess firm up (a sibling to the Reduce Motion support). The empty-tab prompt also shows a focus ring when keyboard-focused.
  • A tab's config menu opens with a right-click (or control-click) instead of a double-click.
Fixed
  • Save failures are no longer silent. If a write to the vault fails, the header shows an amber warning and the save retries automatically, clearing on the next success. Your text always stays in the editor.
  • Sync conflicts don't lose the other side. If a note changes on disk while you have unsaved edits, the incoming version is preserved as a “… (sync conflict …).md” copy before your edits save.
  • No lost edits when switching notes. Switching tabs, stepping siblings, picking a note, or hiding the panel now reads the editor's true current text and saves it before loading the next note.
  • No lost edits on sleep or quit. The debounced autosave is flushed when the machine sleeps or the app quits, not only when the panel hides.
  • Live sync no longer bounces you to the top. When a note changes on disk (Obsidian Sync, iCloud/Dropbox), the update is applied in place, keeping your caret and scroll position.
  • Today tab follows midnight. Left open across midnight, a Today tab rolls over to the new day's note instead of showing yesterday's.
  • Non-standard daily-note formats resolve correctly. Formats using single D, ordinal Do, weekday names, and bracketed literals now match Obsidian's file.
  • Font size only accepts a number (9–48); non-numeric input is rejected instead of snapping to the minimum.
  • Find no longer errors the editor. The custom ⌘F panel could dispatch a query mid-update; it now sets the query only on input.
  • Missing note. A tab whose note was moved or deleted shows a clear “Note not found” state with a re-pick action, instead of an empty editor.
  • Cloud-vault note loading. Notes in a cloud vault (OneDrive, iCloud, Dropbox) that are stored as online-only placeholders are downloaded before opening, so they load correctly.
1.0 Initial release

The first release: a native macOS menu-bar companion for Obsidian. A floating panel of quick note tabs with a live-preview Markdown editor, one global hotkey away.

Added
  • Menu-bar panel. A global hotkey (default ⌥⌘N) opens a floating panel that points at the menu-bar icon, with a stay-on-top option so it floats above other apps, on every Space.
  • Six note tabs. Six fixed, color-coded tabs along the bottom, each bound to a real note in your vault and switchable with ⌘1–⌘6.
  • Live-preview Markdown editor. A CodeMirror 6 editor with a formatting toolbar: headings, bold, italic, code, lists, quotes, and links render inline while the file stays plain Markdown.
  • Clickable task checkboxes. - [ ] / - [x] render as real checkboxes; click one to toggle it done.
  • Autosave & live reload. Edits autosave back to the .md files, and changes made in Obsidian are picked up live in Notesidian.
  • Per-tab icons. Give each tab an icon from SF Symbols or any emoji.
  • Today's Note tabs. Point any tab at the current day's daily note.
  • Inline settings panel. Font, global shortcut, launch-at-login, and stay-on-top, all in one place.
  • Light & dark. Follows your system appearance.
